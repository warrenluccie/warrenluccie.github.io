    跳空因子回测

    🤖 Assistant¶

    已深度思考 我们有两篇关于跳空因子的论文，一篇来自方正证券（2018年），一篇来自华安证券（2020年）。
    两篇论文都是关于股票市场的，现在我们要将跳空因子应用在中证1000股指期货上。

    首先，我们需要理解跳空因子的定义：
    方正证券的跳空因子：过去N个交易日的隔夜涨跌幅绝对值的平均，然后取负号（使得因子值与未来收益正相关）。
    华安证券的跳空因子：过去N个交易日的隔夜涨跌幅绝对值的和（没有取负号，但因子与未来收益负相关，即跳空越大，未来收益越低）。

    但是，请注意，华安证券的因子是绝对值之和，而方正证券是绝对值平均，然后取负。实际上，两个因子本质相同，只是方向和缩放不同。

    另外，华安证券的论文还提到了日内反转因子，以及将隔夜跳空和日内反转结合。但本问题只要求改造跳空因子。

    因此，我们集中精力在跳空因子上。

    由于中证1000股指期货是期货，与股票不同，我们需要考虑期货的连续合约和交易时间。

    步骤：
    1. 数据获取：我们需要中证1000股指期货的日线数据，包括开盘价、收盘价。注意，期货合约有到期日，我们需要使用连续合约。
    2. 因子计算：计算每个交易日的隔夜涨跌幅（今日开盘价/昨日收盘价 - 1），然后取绝对值。接着，计算过去N日的平均值（或和），然后取负号（如果我们希望因子值与未来收益正相关，即跳空越小，未来收益越高）。
    3. 回测：我们需要测试因子在期货上的表现，包括分层回测和IC分析。

    注意：期货是T+0交易，且可以做多和做空，所以我们构造因子时，需要明确因子方向。

    我们按照方正证券的因子定义（取负号）来构建因子，即：
    Jump_N = - mean( abs( overnight_return ) ) over past N days

    但是，由于期货的隔夜跳空可能受到外盘影响，而且期货有夜盘交易，所以我们需要明确隔夜的定义。

    中证1000股指期货的交易时间：
    上午：9:30-11:30
    下午：13:00-15:00
    夜盘：21:00-次日凌晨2:30（？）实际上，中证1000股指期货（IM）有夜盘，交易时间为21:00-23:30（目前中金所股指期货夜盘到23:30，但注意可能调整，以实际为准）

    隔夜的定义：从昨日日盘收盘（15:00）到今日日盘开盘（9:30）之间的间隔，包括夜盘交易。

    但是，由于夜盘交易的存在，隔夜跳空实际上是由夜盘交易和夜间消息共同作用的结果。因此，我们可以用今日日盘开盘价与昨日日盘收盘价之间的涨跌幅作为隔夜跳空。

    然而，注意：夜盘交易是连续的，所以实际上今日日盘开盘价与昨日夜盘收盘价可能更接近，但夜盘收盘价是凌晨2:30（如果有）或者23:30。不过，为了方便，我们仍然用昨日日盘收盘价（15:00）和今日日盘开盘价（9:30）来计算隔夜跳空。

    另一种选择：使用昨日夜盘收盘价（如果有）和今日日盘开盘价，但夜盘收盘价可能不是凌晨2:30，而是23:30。而且，夜盘交易时间较长，可能已经反映了部分夜间消息。

    我们这里按照简单处理，使用昨日日盘收盘价和今日日盘开盘价来计算隔夜跳空。

    步骤：

    1. 读取数据：假设我们有一个DataFrame，包含日期、开盘价、收盘价等。
    2. 计算隔夜收益率：当日开盘价 / 昨日收盘价 - 1
    3. 计算隔夜跳空缺口的绝对值：abs(隔夜收益率)
    4. 计算过去N日的平均绝对值：rolling(N).mean()
    5. 取负号：得到因子值

    注意：期货数据需要连续合约，我们可以使用主力合约连续，或者指数连续。这里假设我们已经有了连续合约数据。

    然后，我们需要进行回测，验证因子在期货上的有效性。

    回测方法：
    1. 分层回测：每月末（或每周，根据调仓频率）根据因子值排序，分为5组或10组，然后计算每组下一期的收益。
    2. 计算IC：因子值与下期收益率的相关系数。

    注意：期货可以双向交易，所以我们也可以构建多空组合。

    由于期货是保证金交易，我们需要考虑保证金和手续费，但因子测试可以先不考虑这些，只计算收益率。

    下面，我们用Python实现。

    假设我们已经有了中证1000股指期货连续合约的日线数据（开盘价、收盘价），并且数据已经按日期排序。

    我们首先计算因子，然后进行分层回测和IC分析。

    注意：期货的收益率计算：使用收盘价到收盘价的收益率，或者使用开盘价到开盘价？这里我们使用收盘价到收盘价的收益率作为未来一期的收益。

    但是，注意：因子计算使用的是隔夜跳空，而未来收益可以是持有期的收益，比如持有1天、5天、20天等。

    论文中股票是月度调仓，但期货可以更灵活。我们可以尝试不同的调仓频率。

    我们先按照月度调仓来测试，即每月末调仓，持有下一个月。

    步骤：
    1. 计算因子：在每个交易日，计算过去N日的平均隔夜跳空绝对值（取负）。
    2. 每月末，根据因子值排序，分组。
    3. 计算每组下个月的收益率（使用收盘价计算）。
    4. 画图，计算多空收益、IC等。

    由于期货数据可能时间跨度不长，我们需要足够长的历史数据。

    下面，我们开始写代码。

    def calculate_overnight_gap(self):
        """计算隔夜跳空"""
        print("计算隔夜跳空因子...")

        # 隔夜收益率：今日开盘 / 昨日收盘 - 1
        self.futures_data['overnight_return'] = self.futures_data['open'] / self.futures_data['close'].shift(1) - 1

        # 对数隔夜收益率
        self.futures_data['log_overnight_return'] = (
            self.futures_data['log_open'] - self.futures_data['log_close'].shift(1)
        )

        # 日内收益率：今日收盘 / 今日开盘 - 1
        self.futures_data['intraday_return'] = self.futures_data['close'] / self.futures_data['open'] - 1

        # 对数日内收益率
        self.futures_data['log_intraday_return'] = (
            self.futures_data['log_close'] - self.futures_data['log_open']
        )

        # 跳空缺口的绝对值
        self.futures_data['gap_abs'] = np.abs(self.futures_data['overnight_return'])
        self.futures_data['log_gap_abs'] = np.abs(self.futures_data['log_overnight_return'])

        print("隔夜跳空计算完成")

        return self.futures_data

    def construct_gap_factors(self):
        """构造跳空因子（方正证券方法）"""
        print("构造跳空因子...")

        for window in self.params['gap_windows']:
            # 过去N日跳空缺口的平均值（取负号，使得因子值与未来收益正相关）
            factor_name = f'JUMP_{window}'
            self.futures_data[factor_name] = -self.futures_data['log_gap_abs'].rolling(window).mean()

            # 存储因子信息
            self.factors[factor_name] = {
                'window': window,
                'description': f'过去{window}日跳空缺口的负平均值',
                'direction': '正'  # 因子值越大，未来收益越高
            }

        print(f"构造了{len(self.factors)}个跳空因子")
        return self.futures_data

    def construct_enhanced_gap_factors(self):
        """构造增强跳空因子（华安证券方法）"""
        print("构造增强跳空因子...")

        # 日内黄金分割反转因子（10点后）
        # 注：期货每分钟数据需另获取，这里用简化方法
        # 假设10:00价格近似为开盘后30分钟均价
        self.futures_data['price_10am'] = (self.futures_data['open'] + self.futures_data['high'].rolling(30).mean()) / 2

        # 日内10点至收盘收益率
        self.futures_data['intraday_10am_return'] = (
            self.futures_data['log_close'] - np.log(self.futures_data['price_10am'])
        )

        # 20日日内黄金分割反转因子
        window = 20
        factor_name = f'INTRA_REVERSAL_{window}'
        self.futures_data[factor_name] = -self.futures_data['intraday_10am_return'].rolling(window).sum()

        self.factors[factor_name] = {
            'window': window,
            'description': f'过去{window}日10点至收盘收益率的负和',
            'direction': '正'
        }

        # 隔夜跳空因子（绝对值累加）
        for window in [5, 10, 20]:
            factor_name = f'OVERNIGHT_GAP_{window}'
            self.futures_data[factor_name] = self.futures_data['log_gap_abs'].rolling(window).sum()

            # 注意：这里是正的累加，预期与未来收益负相关
            self.factors[factor_name] = {
                'window': window,
                'description': f'过去{window}日隔夜跳空绝对值累加',
                'direction': '负'
            }

        print(f"增强因子构造完成，总因子数: {len(self.factors)}")
        return self.futures_data

    def calculate_future_returns(self):
        """计算未来收益率"""
        print("计算未来收益率...")

        for window in self.params['return_windows']:
            # 未来N日收益率（对数）
            future_return_col = f'future_{window}d_return'
            self.futures_data[future_return_col] = (
                self.futures_data['log_close'].shift(-window) - self.futures_data['log_close']
            )

            # 未来N日简单收益率
            self.futures_data[f'future_{window}d_simple_return'] = (
                self.futures_data['close'].shift(-window) / self.futures_data['close'] - 1
            )

        print("未来收益率计算完成")
        return self.futures_data

    def calculate_ic_analysis(self, factor_name='JUMP_10', future_window=20):
        """计算IC分析"""
        print(f"计算{factor_name}因子的IC分析...")

        # 确保数据对齐
        df = self.futures_data[[factor_name, f'future_{future_window}d_return']].dropna()

        # 计算Rank IC（斯皮尔曼相关系数）
        ic_series = df.groupby(df.index.to_period('M')).apply(
            lambda x: x[factor_name].corr(x[f'future_{future_window}d_return'], method='spearman')
        )

        # 计算IC统计
        ic_mean = ic_series.mean()
        ic_std = ic_series.std()
        ic_ir = ic_mean / ic_std if ic_std != 0 else 0
        ic_positive_ratio = (ic_series > 0).mean()

        ic_stats = {
            'IC均值': ic_mean,
            'IC标准差': ic_std,
            'ICIR': ic_ir,
            'IC正比例': ic_positive_ratio,
            'IC序列': ic_series
        }

        print(f"{factor_name} IC分析结果:")
        print(f"  IC均值: {ic_mean:.4f}")
        print(f"  IC标准差: {ic_std:.4f}")
        print(f"  ICIR: {ic_ir:.4f}")
        print(f"  IC正比例: {ic_positive_ratio:.2%}")

        return ic_stats

    def factor_group_analysis(self, factor_name='JUMP_10', future_window=20, group_num=10):
        """因子分组分析"""
        print(f"进行{factor_name}因子分组分析...")

        # 按月调仓
        df = self.futures_data.copy()
        df['month'] = df.index.to_period('M')

        group_returns = []
        group_net_values = []

        for month, month_data in df.groupby('month'):
            # 剔除缺失值
            valid_data = month_data[[factor_name, f'future_{future_window}d_simple_return']].dropna()

            if len(valid_data) < group_num:
                continue

            # 按因子值分组
            valid_data['group'] = pd.qcut(valid_data[factor_name], q=group_num, labels=False, duplicates='drop')

            # 计算每组平均收益
            month_group_returns = valid_data.groupby('group')[f'future_{future_window}d_simple_return'].mean()
            group_returns.append(month_group_returns)

        # 合并各月结果
        if group_returns:
            all_group_returns = pd.concat(group_returns, axis=1).T
            avg_group_returns = all_group_returns.mean() * 20  # 年化（假设20个交易日/月）

            # 计算多空收益
            long_return = avg_group_returns.iloc[-1]  # 因子值最大组（多头）
            short_return = avg_group_returns.iloc[0]   # 因子值最小组（空头）
            long_short_spread = long_return - short_return

            # 计算分组净值
            cumulative_returns = (1 + all_group_returns).cumprod()

            results = {
                'avg_group_returns': avg_group_returns,
                'long_return': long_return,
                'short_return': short_return,
                'long_short_spread': long_short_spread,
                'cumulative_returns': cumulative_returns,
                'all_group_returns': all_group_returns
            }

            print(f"分组分析结果:")
            print(f"  多头组年化收益: {long_return:.2%}")
            print(f"  空头组年化收益: {short_return:.2%}")
            print(f"  多空价差: {long_short_spread:.2%}")

            return results
        else:
            print("分组分析失败：数据不足")
            return None

    def construct_composite_factor(self):
        """构造合成因子（融合昼夜信息）"""
        print("构造昼夜合成因子...")

        # 日内黄金分割反转因子（正相关）
        intra_factor = 'INTRA_REVERSAL_20'

        # 隔夜跳空因子（负相关，需取负号）
        overnight_factor = 'OVERNIGHT_GAP_10'

        # 标准化因子
        self.futures_data[f'{intra_factor}_zscore'] = (
            (self.futures_data[intra_factor] - self.futures_data[intra_factor].rolling(60).mean()) 
            / self.futures_data[intra_factor].rolling(60).std()
        )

        self.futures_data[f'{overnight_factor}_zscore'] = (
            (self.futures_data[overnight_factor] - self.futures_data[overnight_factor].rolling(60).mean()) 
            / self.futures_data[overnight_factor].rolling(60).std()
        )

        # 合成因子（6:4权重，参考华安证券）
        self.futures_data['COMPOSITE_FACTOR'] = (
            0.6 * self.futures_data[f'{intra_factor}_zscore'] 
            - 0.4 * self.futures_data[f'{overnight_factor}_zscore']  # 取负号
        )

        self.factors['COMPOSITE_FACTOR'] = {
            'description': '昼夜合成因子（60%日内反转 + 40%隔夜跳空）',
            'direction': '正'
        }

        print("合成因子构造完成")
        return self.futures_data

    def backtest_strategy(self, factor_name='COMPOSITE_FACTOR', future_window=5, 
                         transaction_cost=0.0003, initial_capital=1000000):
        """策略回测"""
        print(f"对{factor_name}进行策略回测...")

        df = self.futures_data.copy()

        # 生成交易信号（每月调仓）
        df['signal'] = 0
        df['position'] = 0

        # 每月最后一个交易日调仓
        monthly_dates = df.resample('M').last().index
        monthly_dates = [date for date in monthly_dates if date in df.index]

        for i in range(len(monthly_dates) - 1):
            rebalance_date = monthly_dates[i]
            next_rebalance_date = monthly_dates[i + 1]

            # 获取调仓日的因子值
            factor_value = df.loc[rebalance_date, factor_name]

            if pd.isna(factor_value):
                continue

            # 生成信号（简单多头策略：因子值大于0做多，小于0做空）
            signal = 1 if factor_value > 0 else -1

            # 在调仓期间保持信号
            mask = (df.index >= rebalance_date) & (df.index < next_rebalance_date)
            df.loc[mask, 'signal'] = signal
            df.loc[mask, 'position'] = signal  # 满仓

        # 计算策略收益（考虑交易成本）
        df['strategy_return'] = df['position'].shift(1) * df['close_return']

        # 减去年化交易成本（每月调仓一次）
        trade_dates = df[df['position'] != df['position'].shift(1)].index
        for trade_date in trade_dates:
            if trade_date in df.index:
                df.loc[trade_date, 'strategy_return'] -= transaction_cost

        # 计算净值
        df['strategy_cum_return'] = (1 + df['strategy_return'].fillna(0)).cumprod()
        df['benchmark_cum_return'] = (1 + df['close_return'].fillna(0)).cumprod()

        # 计算绩效指标
        strategy_returns = df['strategy_return'].dropna()
        benchmark_returns = df['close_return'].dropna()

        # 年化收益率
        annual_trading_days = 252
        strategy_annual_return = (1 + strategy_returns.mean()) ** annual_trading_days - 1
        benchmark_annual_return = (1 + benchmark_returns.mean()) ** annual_trading_days - 1

        # 年化波动率
        strategy_annual_vol = strategy_returns.std() * np.sqrt(annual_trading_days)
        benchmark_annual_vol = benchmark_returns.std() * np.sqrt(annual_trading_days)

        # 夏普比率
        risk_free_rate = 0.03  # 3%无风险利率
        strategy_sharpe = (strategy_annual_return - risk_free_rate) / strategy_annual_vol
        benchmark_sharpe = (benchmark_annual_return - risk_free_rate) / benchmark_annual_vol

        # 最大回撤
        strategy_cummax = df['strategy_cum_return'].cummax()
        strategy_drawdown = (df['strategy_cum_return'] - strategy_cummax) / strategy_cummax
        strategy_max_drawdown = strategy_drawdown.min()

        benchmark_cummax = df['benchmark_cum_return'].cummax()
        benchmark_drawdown = (df['benchmark_cum_return'] - benchmark_cummax) / benchmark_cummax
        benchmark_max_drawdown = benchmark_drawdown.min()

        # 胜率
        strategy_win_rate = (strategy_returns > 0).mean()

        # 盈亏比
        winning_returns = strategy_returns[strategy_returns > 0]
        losing_returns = strategy_returns[strategy_returns <= 0]
        profit_loss_ratio = abs(winning_returns.mean() / losing_returns.mean()) if len(losing_returns) > 0 else np.inf

        performance = {
            '策略年化收益率': strategy_annual_return,
            '基准年化收益率': benchmark_annual_return,
            '策略年化波动率': strategy_annual_vol,
            '基准年化波动率': benchmark_annual_vol,
            '策略夏普比率': strategy_sharpe,
            '基准夏普比率': benchmark_sharpe,
            '策略最大回撤': strategy_max_drawdown,
            '基准最大回撤': benchmark_max_drawdown,
            '策略胜率': strategy_win_rate,
            '策略盈亏比': profit_loss_ratio,
            '净值曲线': df[['strategy_cum_return', 'benchmark_cum_return']]
        }

        print(f"回测结果:")
        print(f"  策略年化收益: {strategy_annual_return:.2%}")
        print(f"  基准年化收益: {benchmark_annual_return:.2%}")
        print(f"  策略夏普比率: {strategy_sharpe:.2f}")
        print(f"  策略最大回撤: {strategy_max_drawdown:.2%}")
        print(f"  策略胜率: {strategy_win_rate:.2%}")
        print(f"  策略盈亏比: {profit_loss_ratio:.2f}")

        return performance

    def analyze_factor_decay(self, factor_name='JUMP_10'):
        """分析因子衰减"""
        print(f"分析{factor_name}因子衰减...")

        ic_by_horizon = {}
        horizons = [1, 5, 10, 20, 40, 60]

        for horizon in horizons:
            future_return_col = f'future_{horizon}d_return'
            if future_return_col not in self.futures_data.columns:
                continue

            # 计算IC
            df = self.futures_data[[factor_name, future_return_col]].dropna()
            ic = df[factor_name].corr(df[future_return_col], method='spearman')
            ic_by_horizon[horizon] = ic

        # 绘制衰减曲线
        horizons_list = list(ic_by_horizon.keys())
        ic_values = list(ic_by_horizon.values())

        plt.figure(figsize=(10, 6))
        plt.plot(horizons_list, ic_values, marker='o', linewidth=2, markersize=8)
        plt.axhline(y=0, color='r', linestyle='--', alpha=0.5)
        plt.xlabel('预测周期（天）')
        plt.ylabel('Rank IC')
        plt.title(f'{factor_name}因子衰减曲线')
        plt.grid(True, alpha=0.3)
        plt.show()

        return ic_by_horizon

    def visualize_results(self, factor_name='JUMP_10'):

# 高级功能：考虑期货特性的增强
class IM1000EnhancedGapFactor(IM1000GapFactor):
    """中证1000股指期货增强跳空因子"""

    def __init__(self, *args, **kwargs):
        super().__init__(*args, **kwargs)
        self.liquidity_data = None

    def calculate_liquidity_adjusted_factors(self):
        """考虑流动性的调整因子"""
        print("计算流动性调整因子...")

        # 计算流动性指标
        self.futures_data['volume_ma'] = self.futures_data['volume'].rolling(20).mean()
        self.futures_data['volume_ratio'] = self.futures_data['volume'] / self.futures_data['volume_ma']
        self.futures_data['turnover_ma'] = self.futures_data['turnover'].rolling(20).mean()
        self.futures_data['turnover_ratio'] = self.futures_data['turnover'] / self.futures_data['turnover_ma']

        # 流动性加权跳空因子
        for window in [5, 10, 20]:
            # 基础跳空因子
            gap_factor = f'JUMP_{window}'
            liquidity_factor = f'liquidity_adj_JUMP_{window}'

            # 使用成交量倒数加权（流动性越差，权重越低）
            weights = 1 / self.futures_data['volume_ratio'].clip(lower=0.5, upper=2)
            weighted_gap = self.futures_data['log_gap_abs'].rolling(window).apply(
                lambda x: np.average(x, weights=weights.loc[x.index[-len(x):]]), raw=False
            )

            self.futures_data[liquidity_factor] = -weighted_gap
            self.factors[liquidity_factor] = {
                'window': window,
                'description': f'流动性调整的{window}日跳空因子',
                'direction': '正'
            }

        print("流动性调整因子计算完成")
        return self.futures_data

    def calculate_volatility_adjusted_factors(self):
        """考虑波动率的调整因子"""
        print("计算波动率调整因子...")

        # 计算波动率
        self.futures_data['volatility_20d'] = self.futures_data['close_return'].rolling(20).std() * np.sqrt(252)

        for window in [5, 10, 20]:
            # 基础跳空因子
            gap_factor = f'JUMP_{window}'
            vol_factor = f'vol_adj_JUMP_{window}'

            # 跳空幅度相对于波动率的比率
            avg_gap = self.futures_data['log_gap_abs'].rolling(window).mean()
            avg_vol = self.futures_data['volatility_20d'].rolling(window).mean()

            self.futures_data[vol_factor] = -avg_gap / (avg_vol + 1e-6)
            self.factors[vol_factor] = {
                'window': window,
                'description': f'波动率调整的{window}日跳空因子',
                'direction': '正'
            }

        print("波动率调整因子计算完成")
        return self.futures_data

    def calculate_implied_funding_rate_effect(self):
        """考虑资金成本影响"""
        print("计算资金成本调整...")

        # 模拟资金成本（期货贴水/升水）
        # 实际应用中应从期货实际数据计算
        self.futures_data['basis'] = (self.futures_data['close'] - self.futures_data['close'].rolling(20).mean()) / self.futures_data['close'].rolling(20).mean()

        # 资金成本调整的跳空因子
        for window in [5, 10, 20]:
            gap_factor = f'JUMP_{window}'
            funding_factor = f'funding_adj_JUMP_{window}'

            # 当期货大幅贴水时，跳空效应可能减弱
            basis_effect = np.where(self.futures_data['basis'] < -0.01, 0.5, 1.0)
            basis_effect = np.where(self.futures_data['basis'] > 0.01, 1.5, basis_effect)

            self.futures_data[funding_factor] = self.futures_data[gap_factor] * basis_effect
            self.factors[funding_factor] = {
                'window': window,
                'description': f'资金成本调整的{window}日跳空因子',
                'direction': '正'
            }

        print("资金成本调整计算完成")
        return self.futures_data

    def construct_multi_timeframe_factors(self):
        """构造多时间周期因子"""
        print("构造多时间周期因子...")

        # 不同时间周期的跳空因子
        timeframes = {
            'intraday': ('09:30', '15:00'),  # 日盘
            'overnight': ('15:00', '09:30'),  # 隔夜
            'night': ('21:00', '23:30'),      # 夜盘（简化处理）
        }

        for tf_name, (start_time, end_time) in timeframes.items():
            # 简化处理：使用不同时间段的收益率波动
            if tf_name == 'intraday':
                # 日盘波动
                self.futures_data[f'{tf_name}_vol'] = (
                    self.futures_data['high'] / self.futures_data['low'] - 1
                ).rolling(5).mean()

            elif tf_name == 'overnight':
                # 隔夜跳空
                self.futures_data[f'{tf_name}_gap'] = self.futures_data['gap_abs']

            # 构造多周期合成因子
            if 'intraday_vol' in self.futures_data.columns and 'overnight_gap' in self.futures_data.columns:
                intra_vol_z = (self.futures_data['intraday_vol'] - self.futures_data['intraday_vol'].rolling(20).mean()) / self.futures_data['intraday_vol'].rolling(20).std()
                overnight_gap_z = (self.futures_data['overnight_gap'] - self.futures_data['overnight_gap'].rolling(20).mean()) / self.futures_data['overnight_gap'].rolling(20).std()

                self.futures_data['multi_timeframe_factor'] = intra_vol_z - overnight_gap_z
                self.factors['multi_timeframe_factor'] = {
                    'description': '多时间周期合成因子（日盘波动 - 隔夜跳空）',
                    'direction': '正'
                }

        print("多时间周期因子构造完成")
        return self.futures_data

# 实际期货交易接口示例
class IMActualTrading:
    """中证1000股指期货实际交易类"""

    def __init__(self):
        self.contract_multiplier = 200  # 合约乘数
        self.margin_rate = 0.12  # 保证金率
        self.transaction_fee = 0.000023  # 手续费率

    def calculate_position_size(self, capital, volatility):
        """基于波动率的仓位计算"""
        # 凯利公式变体
        risk_per_trade = 0.02  # 单笔风险2%
        position_value = capital * risk_per_trade / volatility
        contracts = int(position_value / (self.contract_multiplier * self.margin_rate))
        return max(1, contracts)

    def backtest_with_leverage(self, signals, prices, initial_capital=1000000):
        """带杠杆的回测"""
        positions = signals.shift(1)  # 滞后一期
        returns = positions * prices.pct_change()

        # 计算保证金占用
        margin_required = abs(positions) * prices * self.contract_multiplier * self.margin_rate

        # 计算杠杆后收益
        levered_returns = returns * (initial_capital / margin_required).clip(upper=3)  # 最大3倍杠杆

        # 扣除手续费
        trade_changes = (positions != positions.shift(1)).astype(int)
        levered_returns -= trade_changes * self.transaction_fee

        return levered_returns.cumsum()

    class RiskManagement:
    """跳空因子交易风险控制"""

    def __init__(self):
        self.max_drawdown_limit = -0.15  # 最大回撤限制
        self.position_limit = 0.8  # 最大仓位限制
        self.stop_loss = 0.05  # 止损线

    def dynamic_position_adjustment(self, current_drawdown, volatility):
        """动态仓位调整"""
        if current_drawdown < self.max_drawdown_limit:
            return 0  # 暂停交易

        # 波动率调整仓位
        adj_position = self.position_limit * (0.02 / volatility)  # 目标波动率2%
        return min(adj_position, self.position_limit)

    def gap_size_filter(self, gap_ratio, threshold=0.03):
        """跳空大小过滤"""
        # 过大跳空可能不适合交易
        if abs(gap_ratio) > threshold:
            return False
        return True

    def liquidity_filter(self, volume, avg_volume):
        """流动性过滤"""
        if volume < avg_volume * 0.5:
            return False
        return True
