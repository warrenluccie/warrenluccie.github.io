





## EV与德州扑克



**EV（Expected Value，期望值）**是Texas Hold'em（德州扑克）决策体系的核心概念。职业玩家、博弈论分析以及现代求解器（solver）策略几乎都围绕 **EV最大化** 展开。

下面从**数学定义 → 扑克应用 → 实战计算 → 职业玩家视角**系统说明。

------

### 一、EV的数学定义

期望值：
$$
\huge EV = \sum (P_i \times V_i)
$$



- (P_i)：事件发生概率
- (V_i)：该事件结果收益

EV表示：

**在无限重复的情况下，每次行动平均能赢多少钱。**

**判断原则**

- EV > 0 → 长期盈利（+EV）
- EV = 0 → 长期盈亏平衡
- EV < 0 → 长期亏损（-EV）

扑克本质：

**不断选择 +EV 行动。**

------

# 二、EV在德州扑克中的三种核心应用

德州中的EV通常体现在三个层面：

### 1 底池赔率（Pot Odds）

判断**是否跟注**

公式

[
Required\ Equity = \frac{Call}{Pot + Call}
]

例子：

底池 100
对手下注 50

你需要跟注 50

[
Equity = \frac{50}{150} = 33%
]

如果你的胜率 >33%

则：

**Call = +EV**

------

### 2 手牌胜率EV

完整EV公式：

[
EV = (WinRate \times Pot) - (LoseRate \times Call)
]

例子：

底池：100
对手 all-in 50

你胜率：

40%

[
EV = (0.4 \times 150) - (0.6 \times 50)
]

[
EV = 60 - 30 = +30
]

长期每次平均赚 **30**

------

### 3 Bluff EV（诈唬期望值）

诈唬的EV：

[
EV = (Fold% \times Pot) - ((1-Fold%) \times Bet)
]

例子：

底池 100

你下注 70 bluff

对手弃牌概率：

50%

[
EV = (0.5 \times 100) - (0.5 \times 70)
]

[
EV = 50 - 35 = +15
]

诈唬 **盈利**

------

# 三、职业玩家的EV结构

------

**整局策略EV**

例如：

- exploit策略

比较

| 策略    | EV        |
| ------- | --------- |
| GTO     | +1bb/hand |
| Exploit | +3bb/hand |

------

# 四、EV与方差（Variance）

]

**方差**

## 扑克 EV → 交易系统 Expectancy 的完整数学统一模型



扑克中的 **EV（Expected Value）** 与交易系统中的 **Expectancy（期望收益）** 在数学结构上完全同构。本质上二者都是**重复博弈中的期望收益优化问题**。下面给出一个从 **概率论 → 资金管理 → 系统收益率** 的统一模型。

------

# 一、统一的期望收益模型

无论是交易还是Texas Hold'em，单次决策的数学结构都是：

[
EV = \sum_{i=1}^{n} P_i \times R_i
]

其中：

- (P_i) ：结果 (i) 发生概率
- (R_i) ：该结果的收益（可以为负）

在金融交易中，这个公式通常写成 **系统 Expectancy**：

[
E = (P_w \times W) - (P_l \times L)
]

变量含义：

| 符号  | 含义     |
| ----- | -------- |
| (P_w) | 胜率     |
| (P_l) | 失败概率 |
| (W)   | 平均盈利 |
| (L)   | 平均亏损 |

注意：

[
P_l = 1 - P_w
]

------

# 二、交易系统 Expectancy 的标准形式

交易领域常写成：

[
E = (WinRate \times AvgWin) - (LossRate \times AvgLoss)
]

如果用 **R倍数（Risk Multiple）** 表示：

[
E = P_w \times R_w - (1-P_w)
]

其中：

- (R_w)：平均盈利倍数（Reward/Risk）

------

# 三、扑克与交易变量对应关系

| 扑克概念        | 交易概念   |
| --------------- | ---------- |
| Pot             | 市场机会   |
| Bet             | 仓位       |
| Win probability | 胜率       |
| Payoff          | 盈亏比     |
| EV              | Expectancy |
| Bankroll        | 资金曲线   |

数学完全一致：

[
Edge = Probability \times Payoff
]

------

# 四、系统收益的核心公式

长期收益率：

[
TotalProfit = N \times E
]

其中：

- (N) = 交易次数
- (E) = 单次期望

这就是交易中非常重要的一条规律：

**盈利 = 优势 × 频率**

------

# 五、典型交易系统示例

假设：

胜率：

50%

平均盈利：

2R

平均亏损：

1R

Expectancy：

[
E = 0.5 \times 2 - 0.5 \times 1
]

[
E = 0.5R
]

含义：

**每笔交易平均赚 0.5R**

如果一年交易 1000 次：

[
Total = 1000 \times 0.5R = 500R
]

------

# 六、胜率与盈亏比的关系

Expectancy 可以写成：

[
E = P_w \times R - (1-P_w)
]

当

[
E > 0
]

系统盈利。

例如：

| 胜率 | 盈亏比 | Expectancy |
| ---- | ------ | ---------- |
| 30%  | 4:1    | +0.5R      |
| 40%  | 3:1    | +0.2R      |
| 50%  | 2:1    | +0.5R      |
| 60%  | 1.5:1  | +0.5R      |

重要结论：

**胜率不是最重要变量**

关键是：

**Edge = WinRate × Payoff**

------

# 七、加入仓位后的完整模型

如果加入仓位 (f)：

[
Growth = E \times f
]

更完整：

[
Capital_{t+1} = Capital_t \times (1 + fR)
]

长期资金增长：

[
Capital_T = Capital_0 \times \prod (1 + fR_i)
]

这就是 **资金曲线的乘法增长模型**。

------

# 八、Kelly Criterion（凯利公式）

最优仓位：

[
f^* = \frac{bp - q}{b}
]

其中：

- (b)：盈亏比
- (p)：胜率
- (q = 1-p)

该公式最早用于赌局概率优化，现在被大量对冲基金采用。

------

# 九、完整统一模型

交易与扑克的统一数学结构：

[
EV = Edge \times Frequency
]

展开：

[
Profit = N \times (P_w \times W - P_l \times L)
]

再加入仓位：

[
Capital_{t+1} = Capital_t \times (1 + f \times EV)
]

最终系统：

[
Capital_T = Capital_0 \times \prod_{i=1}^{N}(1 + fR_i)
]

------

# 十、真正职业玩家理解的核心

专业玩家只关心三个变量：

1️⃣ **Edge（优势）**

[
Edge = EV
]

2️⃣ **Volume（频率）**

[
N
]

3️⃣ **Risk（仓位）**

[
f
]

最终：

[
Profit = Edge \times Volume \times Position
]

------

# 十一、为什么扑克玩家容易成为顶级交易员

]

## 德州扑克基本术语





Texas Hold'em（德州扑克）有一套高度标准化的术语体系。理解这些术语是阅读策略书、分析牌局或使用求解器（solver）的基础。下面按 **牌局结构 → 行动 → 位置 → 牌力 → 概率与策略 → 资金管理** 六个模块系统整理。

------

# 一、牌局结构术语（Game Structure）

**Blinds（盲注）**

- 小盲（Small Blind, SB）
- 大盲（Big Blind, BB）
  用于强制下注，保证底池存在。

**Button（BTN）**
庄家位置，最后行动的位置。

**Dealer**
发牌位置（通常由 Button 标识）。

**Pot（底池）**
所有玩家当前投入的筹码总和。

**Board（公共牌）**
桌面五张公共牌。

------

# 二、下注与行动术语（Actions）

**Check（过牌）**
不下注，把行动权交给下家。

**Bet（下注）**
第一个主动投入筹码。

**Call（跟注）**
跟随对手下注。

**Raise（加注）**
在对手下注基础上再加码。

**Re-raise / 3-bet / 4-bet**
连续加注层级：

| 术语       | 含义       |
| ---------- | ---------- |
| Open Raise | 第一次加注 |
| 3-bet      | 第二次加注 |
| 4-bet      | 第三次加注 |
| 5-bet      | 第四次加注 |

**Fold（弃牌）**
放弃手牌退出底池。

**All-in**
将所有筹码投入。

------

# 三、牌局阶段（Street）

德州共有四个下注阶段：

| 阶段    | 说明         |
| ------- | ------------ |
| Preflop | 翻牌前       |
| Flop    | 前三张公共牌 |
| Turn    | 第四张公共牌 |
| River   | 第五张公共牌 |

------

# 四、位置术语（Position）

位置在扑克中非常重要。

| 位置            | 简称 |
| --------------- | ---- |
| Early Position  | EP   |
| Middle Position | MP   |
| Cutoff          | CO   |
| Button          | BTN  |
| Small Blind     | SB   |
| Big Blind       | BB   |

**Position（位置优势）**

后位行动具有信息优势。

------

# 五、牌力术语（Hand Strength）

**Hole Cards（底牌）**
每个玩家两张手牌。

**Nuts**
当前牌面最强牌。

**Top Pair**
最大公共牌配对。

**Second Pair / Third Pair**
第二或第三对子。

**Set**
口袋对子在翻牌形成三条。

**Two Pair**
两对。

**Flush（同花）**

**Straight（顺子）**

**Full House（葫芦）**

**Quads（四条）**

------

# 六、听牌术语（Draws）

**Flush Draw**
差一张同花。

**Straight Draw**

- **Open-ended Straight Draw（OESD）**
  两头顺子听牌
- **Gutshot**
  内嵌顺子听牌

**Backdoor Draw**
需要连续两张牌完成。

------

# 七、概率与数学术语

**Equity（胜率）**
当前手牌赢得底池的概率。

**EV（Expected Value）**
期望收益。

**Pot Odds（底池赔率）**

公式：

[
PotOdds = \frac{Call}{Pot + Call}
]

**Implied Odds（隐含赔率）**

未来可能赢到的筹码。

------

# 八、策略术语

**Bluff（诈唬）**
用弱牌下注让对手弃牌。

**Semi-Bluff（半诈唬）**
既可能逼弃牌，也有听牌胜率。

**Value Bet（价值下注）**
用强牌下注获取价值。

**Continuation Bet（C-Bet）**
翻牌前进攻者在翻牌圈继续下注。

**Slow Play（慢打）**
强牌故意不加注诱导对手。

**Check-Raise**
先过牌再加注。

------

# 九、范围概念（Range）

现代扑克核心概念：

**Range（牌范围）**

指玩家可能持有的所有牌组合。

例：

BTN open range

不是一手牌，而是：

- AA
- AK
- AQ
- AJs
- KQs

等一整套组合。

------

# 十、资金与风险术语

**Stack（筹码量）**

**Effective Stack（有效筹码）**
两名玩家较小的筹码量。

**Bankroll（资金池）**
玩家总资金。

**Buy-in（买入）**
进入牌局的筹码。

------

# 十一、职业玩家常用缩写

| 缩写 | 含义                         |
| ---- | ---------------------------- |
| VPIP | Voluntarily Put Money In Pot |
| PFR  | Preflop Raise                |
| AF   | Aggression Factor            |
| 3B   | 3-Bet                        |
| WTSD | Went to Showdown             |

这些通常用于 HUD（统计软件）。

------

# 十二、最重要的五个扑克核心概念

职业玩家最关注的五个：

1️⃣ Position（位置）
2️⃣ Range（牌范围）
3️⃣ Equity（胜率）
4️⃣ EV（期望值）
5️⃣ Pot Odds（赔率）
