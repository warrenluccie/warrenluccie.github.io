## 两伊战争对大类资产的影响

- 时间：1980年9月22日

这个问题本质上是一次**典型地缘政治冲击 + 原油供给冲击**对大类资产的定价影响分析。

我们分四部分展开：

1. 战争发生时的宏观背景
2. 石油价格反应
3. 黄金价格反应
4. 美股（标普500）反应
5. 与其他战争冲击对比（验证规律）

------

## 一、宏观背景（1980年9月）

📌 时间：1980年9月22日
📌 事件：伊拉克入侵伊朗，两伊战争爆发
📌 背景环境极其关键：

- 1979年伊朗革命 → 第二次石油危机
- 美国CPI通胀 > 13%
- 美联储主席：Paul Volcker
- 利率 > 15%
- 黄金在1980年1月刚刚创历史高点（850美元）

⚠️ 关键点：

> 两伊战争不是在“低通胀环境”下发生的，而是在已经经历石油危机 + 高通胀 + 高利率的背景下。

这决定了资产反应的结构。

------

# 二、石油价格的反应

### 战前油价

- 1978年：~14美元/桶
- 1979年伊朗革命后：飙升至 ~35美元
- 1980年战争前：已处高位

### 战争爆发后

![Image](https://www.researchgate.net/publication/46544077/figure/fig2/AS%3A644287108763648%401530621425068/REAL-OIL-PRICE-FEDERAL-FUNDS-RATE-AND-THE-CIVILIAN-UNEMPLOYMENT-RATE-1978-1985.png)

![Image](https://upload.wikimedia.org/wikipedia/commons/thumb/3/3f/West_Texas_Intermediate_oil_prices_1950%E2%80%932000_%28with_1973_highlight%29.svg/1280px-West_Texas_Intermediate_oil_prices_1950%E2%80%932000_%28with_1973_highlight%29.svg.png)

![Image](https://raw.githubusercontent.com/warrenluccie/quantpictures/main/gep2018a_blog03_chart01)

📊 实际走势：

- 战争爆发初期：油价短期冲高
- 1980年下半年：维持高位
- 1981–1982年：开始下跌

📌 原因：

1. 市场已经提前交易“供应冲击”
2. 全球经济因高利率进入衰退
3. 需求崩溃

👉 结论：

战争并没有推动油价出现“二次超级行情”，因为：

> 供给冲击已经price in

![Image](https://raw.githubusercontent.com/warrenluccie/quantpictures/main/gr-pm-gold-prices-462.gif)

### 关键数据：

- 1980年1月：黄金 850美元（历史极值）
- 1980年9月战争时：约 650美元
- 1981–1982年：持续下跌至 300–400美元区间

📌 为什么战争没有推高黄金？

因为：

1. 通胀预期已见顶
2. Volcker暴力加息
3. 实际利率转正

黄金核心定价公式：

> Gold ≈ - Real Yield + Inflation Fear

当实际利率飙升时：
黄金无法持续上涨。

👉 两伊战争对黄金是“短期扰动”，不是趋势改变。

### 战争爆发时市场状态：

- 1980年美国已经进入衰退
- 1981–1982出现更严重衰退
- 标普500实际表现疲弱

📊 走势特征：

- 战争爆发后：无系统性暴跌
- 真正下跌发生在 1981–1982
- 原因是高利率压制估值

📌 关键逻辑：

战争不是核心变量
真正的核心变量是：

> 实际利率 + 流动性

# 五、结构总结：资产反应逻辑

| 资产 | 短期反应   | 中期趋势   | 核心驱动     |
| ---- | ---------- | ---------- | ------------ |
| 石油 | 小幅冲高   | 随衰退下跌 | 需求坍塌     |
| 黄金 | 短期波动   | 大级别下跌 | 实际利率飙升 |
| 美股 | 无系统崩盘 | 熊市延续   | 高利率压估值 |

------

# 六、与其他战争对比（验证规律）

对比：

- 1990 海湾战争
- 2003 伊拉克战争
- 2022 俄乌战争

发现一致规律：

### 规律1：油价只在“供给意外”时暴涨

如果市场已预期 → 冲高回落

### 规律2：黄金取决于“实际利率”

不是战争本身

### 规律3：股票取决于“流动性环境”

战争影响通常二阶

------

# 七、最核心结论

两伊战争是：

> 地缘政治冲击
> 但资产趋势由宏观货币周期主导

1980年代真正决定资产方向的不是战争，而是：

- Volcker紧缩
- 实际利率转正
- 通胀见顶

------

# 八、如果把它抽象成资产定价框架

资产价格 = f(流动性, 实际利率, 增长, 风险溢价)

战争只影响：

- 风险溢价（短期）
- 能源供给（阶段性）

但如果：

- 实际利率趋势明确
- 经济周期下行

战争改变不了趋势。
