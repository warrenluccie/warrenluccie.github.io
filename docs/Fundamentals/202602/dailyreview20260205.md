# 每日复盘和反省   |  20260205



**A股收盘综述：沪指缩量下跌0.64%，光伏、有色金属领跌**

香港万得通讯社报道，2月5日，A股单边下行，光伏、有色金属板块领跌，大消费逆势走强。

上证指数收跌0.64%报4075.92点，深证成指跌1.44%，创业板指跌1.55%，北证50跌2.03%，科创50跌1.44%，万得全A跌1.11%，万得A500跌1.02%，中证A500跌1.17%。A股全天成交2.19万亿元，上日成交2.5万亿元。

9天春节将至激发消费热情，影视、食品饮料、零售等消费方向集体走高，横店影视、茂业商业、金逸影视、海欣食品等股收获涨停。消息面上，商务部等9部门印发《2026“乐购新春”春节特别活动方案》，鼓励各地增加春节期间消费品以旧换新补贴数量，加大线下实体零售支持力度。开源证券研报指出，春节作为食品消费旺季，备货需求释放有望提振板块。

地方银行普遍走强，厦门银行涨停，重庆银行、南京银行领涨，近日不少中小银行上调了存款利率。房地产股局部活跃，皇庭国际、京投发展、韩建河山涨停。券商股午后一度冲高，华林证券涨停。

**存储芯片等算力硬件股持续低迷，德科立、太辰光、致尚科技等跌逾10%，长飞光纤、炬光科技、天通股份、亨通光电、罗博特科等纷纷大跌。消息面上，美国软件板块周三遭遇2022年以来最严重的抛售，这场由软件股掀起的科技板块抛售潮正不断蔓延，近期备受追捧的存储芯片制造商遭遇“集体踩踏”，闪迪等在AI引爆存储需求叙事中获利颇丰的企业回撤更为剧烈。**

太空光伏概念大幅调整，钧达股份、金辰股份、双良节能等跌停，连城数控、捷佳伟创、欧普泰等跌幅明显。消息面上，中国光伏行业协会执行秘书长刘译阳表示，目前太空光伏技术仍处于探索和验证的初期阶段，确定明确的技术方向为时尚早，这或许是该概念股大幅调整的原因之一。

国际金银价格亚太时段大幅下跌，黄金、有色金属板块再度走低，湖南白银、白银有色等股跌停，晓程科技跌逾10%。

展望后市，东方证券表示，临近春节，活跃资金交投有降温迹象，板块轮动较快，给短线资金带来的体验并不太好。但本轮大跌之后的反弹力度较大，预示着未来稳市预期更加牢固。本轮“走向慢牛”的政策引导将会促使更多的活跃板块不时出现，尤其是科技赛道值得高度关注。

天风证券认为，不论是“十五五”开局之年的政策预期，全球流动性宽松前景，还是居民资金向权益资产配置的趋势，都可能强化节后市场上涨的规律，今年“春节躁动”行情或更持续。此外，今年受“史上超长九天春节假期”的影响，消费需求释放明显早于往年，出行与消费规模有望再突破，市场对“经济开门红”的预期或更稳定。

中信证券研报指出，2026年前后，商业航天（核心股）产业将进入由“技术验证”迈向“规模化产业化”的关键拐点。随着中国星网和G60千帆星座批量化发射、海南商发与商业运载火箭投入使用，大运力、低成本趋势将引领行业开启新时代，太空算力（核心股）进一步打开行业天花板。探月、深空探索、太空旅行等领域的进展将持续拓展产业潜力。投资端，目前锐度较高的方向是可回收火箭、spaceX链、太空算力，而低轨通信卫星链是最先有基本面逻辑和订单支持的细分领域。投资端应更聚焦核心资产，寻找“通胀环节”及“边际新增”方向，看好火箭3D打印、卫星射频天线、卫星碳纤维（核心股）复材、太阳翼、星间激光通信等相关标的。
