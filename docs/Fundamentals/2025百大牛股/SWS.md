



# 申万一级行业和二级行业有哪些

部分典型二级行业如下：

- 农林牧渔：种植业、养殖业、饲料、农产品加工、动物保健
- 基础化工：化学原料、化学制品、农化制品、塑料、橡胶、化学纤维、化学纤维、煤化工
- 有色金属：工业金属、贵金属、小金属、金属新材料
- 电子：半导体、消费电子、元件、光学光电子、电子化学品
- 食品饮料：白酒、啤酒、饮料乳品、食品加工、调味发酵品
- 医药生物：化学制药、中药、生物制品、医疗器械、医疗服务、医药商业
- 电力设备：电池、光伏设备、风电设备、电网设备、其他电源设备
- 机械设备：通用设备、专用设备、自动化设备、工程机械、轨交设备
- 汽车：乘用车、商用车、汽车零部件、汽车服务、摩托车及其他
- 计算机：软件开发、IT服务、计算机设备
- 传媒：游戏、广告营销、影视院线、出版、数字媒体
- 通信：通信设备、通信服务
- 非银金融：证券、保险、多元金融
- 环保：环境治理、环保设备
- 美容护理：化妆品、个护用品、医疗美容

如果你是做行业轮动、行业ETF、PB/PE分位数研究，通常最常用的是一级行业；如果你要做更精细的产业链研究、选股、景气度跟踪，则更适合用二级行业，因为二级行业已经能区分例如“半导体”和“消费电子”、“白酒”和“食品加工”、“光伏设备”和“电池”等差异。

例如你最近在研究估值分位数和行业景气度，通常可以这样分层：

- 一级行业：看大方向（例如电子、医药、电力设备）
- 二级行业：找景气细分（例如半导体、创新药、光伏设备）
- 三级行业：做个股映射（例如模拟芯片、CXO、逆变器）
