# **美股收盘综述：美国三大股指全线收跌，英伟达、特斯拉跌超4%**

> 01-21 05:00

香港万得通讯社报道，周二（1月20日），美国三大股指全线收跌，道指跌1.76%，标普500指数跌2.06%，纳指跌2.39%。

3M公司跌近7%，IBM跌超4%，领跌道指。

万得美国科技七巨头指数跌3.06%，英伟达、特斯拉跌超4%。中概股多数下跌，晶科能源跌超12%，世纪互联跌逾10%。

截至收盘，道指跌1.76%报48488.59点，标普500指数跌2.06%报6796.86点，纳指跌2.39%报22954.32点。



## 板块方面

◆大型科技股全线下跌，万得美国科技七巨头指数跌3.06%。个股方面，英伟达跌超4%，特斯拉跌逾4%，苹果跌超3%，亚马逊跌逾3%，META跌超2%，谷歌跌逾2%，微软跌超1%。

◆银行股全线走低，摩根大通跌超3%，高盛跌近2%，花旗跌逾4%，摩根士丹利跌超3%，美国银行跌逾1%，富国银行跌近2%。

◆航空股多数下跌，波音涨0.54%，美国航空跌超3%，达美航空跌逾4%，西南航空跌超1%，美联航跌超4%。

◆芯片股普遍下跌，费城半导体指数跌1.68%，博通跌超5%，科天半导体跌逾5%，台积电跌超4%，英伟达跌逾4%，高通跌超3%。涨幅方面，英特尔涨超3%，ARM涨逾1%。

◆黄金股表现强劲，盎格鲁黄金涨近8%，金田涨超7%，埃尔拉多黄金涨超6%，哈莫尼黄金涨逾5%，巴里克黄金涨超2%。

◆中概股多数下跌，纳斯达克中国金龙指数跌1.44%，万得中概科技龙头指数跌2.61%。个股方面，晶科能源跌超12%，世纪互联跌逾10%，哔哩哔哩跌近7%，小马智行跌超6%，阿特斯太阳能跌逾5%，唯品会涨近3%，再鼎医药涨超1%，贝壳涨逾1%。



## 宏观方面

◆美国总统特朗普称将从2月1日起对丹麦、挪威、瑞典、法国、德国、英国、荷兰和芬兰出口至美国的所有商品加征10%关税。欧洲国家正考虑采取报复性关税及更广泛的经济反制措施，包括数万亿美元级别的资产抛售。高盛认为，美国对欧洲八国加征10%的关税将通过减少出口，使受影响欧洲国家的实际国内生产总值(GDP)下降0.1%至0.2%。与此同时，通胀影响可能非常微小，在其他条件不变的情况下，泰勒规则将指向适度下调政策利率。而在反制方面，高盛经济学家认为欧盟可能采取三个层面的报复行动，英国采取报复行动的门槛更高，这与英国在去年贸易谈判中的立场一致。

◆美国总统特朗普在得知法国总统马克龙无意加入美国主导的监督加沙地带战后过渡治理的所谓“和平委员会”后，威胁对法国葡萄酒和香槟征收200%的关税。一位接近马克龙的消息人士回应表示，以关税威胁来改变我们的外交政策是不可接受且无效的。

◆美国银行1月基金经理调查显示，随着全球增长预期飙升，全球投资者信心升至2021年7月以来最高水平。地缘政治冲突自2024年10月以来首次成为最大的尾部风险，人工智能泡沫位居第二。现金持有比例降至3.2%的历史新低，而针对市场回调的防护水平已降至2018年1月以来的最低。

◆ADP数据显示，截至2025年12月27日的四周，美国私人部门就业人数周均新增8000人。



## 个股方面

◆奈飞：第四季度营收120.5亿美元，预估119.7亿美元；第四季度每股收益0.56美元，上年同期0.43美元；第四季度自由现金流18.7亿美元，预估14.6亿美元。奈飞预计2026年营收507亿美元至517亿美元，预估509.6亿美元；预计第一季度经营利润39.1亿美元，预估41.8亿美元；预计第一季度每股收益0.76美元，预估0.82美元。奈飞美股盘后跌超4%。

◆美联航：第四季度运营收入达154亿美元，预估为153.7亿美元；第四季度调整后每股收益为3.10美元，预估为2.92美元。美联航盘后涨超1%。

◆OpenAI：将在ChatGPT上推出年龄预测功能，以帮助确定一个账户是否可能属于未成年人（18岁以下人群）。年龄预测功能将在全球范围内推出，欧盟地区将在未来几周内跟进。

◆微软首席执行官萨蒂亚·纳德拉警告称，若人工智能无法得到更广泛应用，这一波繁荣景象可能会消退。

◆马斯克：已将新的X算法开源，该算法采用了与xAI的Grok模型相同的Transformer架构；知道这个算法很笨拙，还需要进行大量的改进，但正在努力实时地、透明地改进它，没有其他社交媒体公司这样做。

◆马斯克旗下xAI正在打造一支“招聘突击队”，借此全面强化顶尖工程师的招聘力度，因应AI热潮带动的激烈人才争夺战。

该团队将直接向马斯克本人报告，专注于以创新方法识别和招聘“世界上最优秀的人才”。在招聘条件上，xAI要求应征者必须能进行“氛围编程”(vibe coding)，并且过去就有打造酷炫产品的经验。该职位工作地点位于美国加州帕罗奥图，年薪介于12万至24万美元之间。

◆台积电持续加大对先进封装技术的投资，正在嘉义AP7工厂新建一条WMCM生产线。因苹果计划将封装技术从目前的InFO（集成扇出型）工艺升级到WMCM（晶圆级多芯片模块）封装。
