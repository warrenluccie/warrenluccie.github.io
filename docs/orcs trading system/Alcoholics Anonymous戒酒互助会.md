# Alcoholics Anonymous   |  戒酒互助会



对于交易员而言，Alcoholics Anonymous 的价值，不在于“戒酒”本身，而在于它背后的行为矫正框架、情绪管理机制和自我约束体系。

很多顶级交易员最后拼的不是技术，而是“避免自我毁灭”的能力。交易和成瘾行为之间有很多相似点：

- 都依赖即时反馈
- 都容易被多巴胺驱动
- 都容易在亏损、压力、孤独、愤怒、兴奋时失控
- 都容易出现“再来一次就翻本”的补偿心理
- 都容易从“理性执行”滑向“冲动行为”



AA 的很多原则，实际上可以迁移到交易系统里。

## ①破坏纪律

​	把“破坏纪律”视为一种复发
AA 的核心思想之一是：问题不是某一次喝酒，而是你失去了对行为的控制。

对交易员来说，真正危险的不是一笔亏损，而是：

- 止损后加仓报复	

- 连续亏损后扩大仓位
- 乱做不属于系统的单子
- 熬夜盯盘
- 频繁看账户盈亏
- 明知不该做却还是去做

很多职业交易员会把这些行为视为“纪律复发”。一旦发生，就要立刻停止交易、复盘，而不是继续加码。





## ②每日自我盘点Daily Inventory

​	强化“每日自我盘点”机制
AA 有一个很重要的步骤：每天做 inventory（自我盘点）。

交易员也非常需要类似机制，比如每天记录：

- 今天是否按系统执行
- 是否有情绪化交易
- 是否出现 FOMO
- 是否因为亏损而改变仓位
- 是否因为盈利而过度自信
- 今天最大的错误是什么
- 明天最需要避免什么

长期看，交易记录的作用不仅是找策略问题，更是找“人格漏洞”。

这和你之前关注的交易员体系里的 trade record 很一致：**交易记录不仅是统计工具，更是心理矫正工具。**



## ③降低冲动性

AA 最有价值的部分：降低冲动性

研究发现，长期参与 AA 的人，冲动性会显著下降，而冲动性下降又会改善情绪、决策和社会功能。([PMC](https://pmc.ncbi.nlm.nih.gov/articles/PMC3558834/?utm_source=chatgpt.com))

对于交易员来说，冲动性下降意味着：

- 更能等待 setup
- 更能接受“今天没机会”
- 更能接受止损
- 更能执行固定仓位
- 更能接受“不交易也是交易”
- 更少出现 revenge trading

交易员最后不是靠“更聪明”赚钱，而是靠“更不冲动”。





##  ④emotional sobriety情绪戒断

  AA 的“情绪戒断”思维很适合交易
AA 后期很强调 emotional sobriety（情绪上的清醒）。

很多交易员并不是因为系统不好亏钱，而是因为：

- 想证明自己是对的
- 害怕错过行情
- 想快速赚回来
- 用交易缓解焦虑、空虚和无聊
- 把盈亏和自我价值绑定

所谓“情绪清醒”，就是能够承认：

“我现在不是在交易机会，我是在交易情绪。”

一旦交易变成情绪出口，账户就会变成情绪垃圾桶。([Verywell Mind](https://www.verywellmind.com/emotional-sobriety-11880678?utm_source=chatgpt.com))



## ⑤群体支持

AA 的群体支持，对交易员尤其重要
交易是高度孤独的职业。很多人亏损时会隐藏、否认、自责，最后越来越封闭。

AA 的群体互助模式，对交易员也很有启发：

- 找几个纪律强的人定期复盘
- 公布自己的交易规则
- 公布最大允许回撤
- 让别人监督自己是否破坏系统
- 定期分享错误案例

因为人在独处时最容易“合理化错误”。





## ⑥交易员基本功训练必不可少

但 AA 也有局限
AA 适合帮助交易员建立纪律、克制冲动、管理情绪，但它无法替代真正的交易训练：

- 它不能替代风险管理

- 不能替代仓位控制

- 不能替代系统开发

- 不能替代统计优势

- 不能替代市场理解

而且有些人不适应 AA 的宗教色彩或“无力感”叙事，这种情况下可以参考更偏理性训练的方式，比如 SMART Recovery 或 LifeRing Secular Recovery，它们更强调认知行为训练、自我管理和复发预防。([维基百科](https://en.wikipedia.org/wiki/LifeRing_Secular_Recovery?utm_source=chatgpt.com))

如果把 AA 的逻辑翻译成交易语言，本质上就是一句话：

**“你不是在和市场战斗，你是在和自己最容易失控的那部分人格战斗。”**

很多人研究十年技术分析，最后输给的却是自己的冲动、贪婪、恐惧和报复心理。AA 的价值，在于它给了交易员一个“如何管理失控人格”的框架。
