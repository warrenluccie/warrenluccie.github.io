# 乔帮主语录合集 



简介:短短42个月，资金量就从20万暴增到亿元，收益率超过500倍。这个“神话”的主人就是被称为低吸鼻祖的乔帮主。乔帮主相传为北京大学计算机系毕业。自从席位迁到 招商蛇口 工业七路之后，乔帮主一路顺风顺水，风格尤其以强势股低吸闻名，是 网红游资之一。除了招商蛇口工业七路，乔帮主常用席位还有 招商证券 深圳蛇口工业三路。
