



# CPO

ChatGPT的火爆推动全球AI产业化进程的全面提速，AI产业高速发展背后离不开算力的强力支撑，CPO技术的低功耗或成为AI高算力下高能效比方案。

CPO（Co-Packaged Optics，光电共封装）是一种新型的光电集成技术。简单来说，就是把光模块和交换芯片“打包”封装在一起。
