# 国产 CPU 板块深度分析研究

## 一、板块核心标的

### 1. 海光信息 (688041.SH)

| 指标 | 数值 |
|------|------|
| 总市值 | 5700.44 亿元 |
| 最新价 | 248.42 元 |
| 市盈率 (PE_TTM) | 209.11 倍 |

**核心优势：**
- **唯一 x86 授权国产厂商**：拥有 AMD x86 架构授权，CPU 兼容主流生态（Windows Server、Linux、麒麟、UOS、MySQL、Oracle、达梦数据库、PyTorch、TensorFlow）
- **CPU+DCU 双线突破**：海光 CPU 主攻通用服务器，DCU 对标 NVIDIA GPU，兼容"类 CUDA"环境
- **商业落地领先**：金融行业核心交易系统市占率超 15%，政务信创服务器采购国产第一，2025 年服务器出货量超 50 万台
- **财务数据强劲**：2026 年 Q1 营收 40.34 亿元（+56.92%），净利润 6.87 亿元（+31.79%），毛利率 50% 以上

**投资逻辑：**
- 国产高端处理器龙头，x86 架构+GPGPU 双线壁垒
- 2027 年信创渗透深化 +AI 算力需求爆发，打开千亿级市场空间
- 国有资本深度绑定（曙光信息持股 27.96%，中科院系）

**风险：**
- 美国出口管制升级可能影响先进制程供应链
- AI 算力需求波动影响 DCU 放量节奏

### 2. 龙芯中科 (688047.SH)

| 指标 | 数值 |
|------|------|
| 总市值 | 553.38 亿元 |
| 最新价 | 139.96 元 |
| 市盈率 (PE_TTM) | -121.98 倍 |

**核心技术产品：**
- **3A6000**（桌面）：当前主流产品线
- **3B6000M**（移动/边缘）：低功耗场景，较同性能 x86 低 30%-40%
- **3C6000 系列**（服务器）：2025 年 6 月发布，单芯片 16 核 32 线程，性能对标 Intel 至强 Silver 4314（16 核）、Gold 6338（32 核）；4 硅封装 64 核版本性能超 Intel 至强 Platinum 8380（40 核）
- **9A1000**（GPU）：2025 年流片，定位入门级显卡，AI 推理 32TOPS，对标 AMD RX550

**投资逻辑：**
- **完全自主指令集 LoongArch**：不依赖国外授权，生态独立性最强
- **信创渗透深化**：从党政向金融、能源、电信延伸，2027 年营收有望达 12-16 亿元（较 2025 年翻倍）
- **自研 GPU 开启第二曲线**：9A1000 有望 1-3 年内商业化落地

**风险：**
- **持续亏损**：2024 年研发费用率 85%，现金流紧张（经营性现金流 -3.35 亿元）
- **生态建设滞后**：二进制翻译+Linux 社区分支仍在完善，市场化转型艰难
- **客户集中度高**：前五大客户贡献超 70% 收入
- **估值已较高**：2026-2027 年 PE 中位数 200-250 倍，显著高于历史区间

**最新产品进展：**
- **JM11 系列 GPU**：2024 年研发成功，已完成流片/封装，支持硬件虚拟化，应用于云桌面、云渲染、地理信息系统
- **景宏系列**：持续迭代，拓展 AI 计算场景

**投资逻辑：**
- **国内少数自主 GPU 厂商**：军民融合背景，军工信息化核心标的
- **芯片业务成为核心驱动**：2024 年增长超三成，2025 年有望加速放量
- **AI 算力需求爆发**：国产 GPU 替代窗口期，云边端场景拓展

**风险：**
- **业绩承压**：2024 年亏损 1.65 亿元，2025 年 Q1 仍亏 5485 万元
- **传统主业下滑**：军用领域需求波动，客单价受审价影响
- **生态竞争壁垒**：CUDA 护城河深厚，民用市场拓展难度大

## 三、产业链全景

### 1. 政策驱动
- **信创 2027 目标**：关键领域国产芯片占比超 80%
- **"东数西算"战略**：2025 年国产服务器芯片市场规模预计超 1200 亿元
- **AI+ 行动**：大模型训练/智算中心建设加速国产算力需求

### 2. 竞争格局
| 维度 | 海光信息 | 龙芯中科 | 景嘉微 |
|------|----------|----------|--------|
| **架构** | x86（授权） | LoongArch（自研） | 自研 GPU 架构 |
| **生态** | 成熟，兼容主流 | 建设中，二进制翻译 | 军事应用成熟，民用待拓展 |
| **商业落地** | 金融/政务/电信渗透高 | 政务为主，市场化转型中 | 军工为主，民用云边端 |
| **财务** | 盈利增长强劲 | 持续亏损，高研发 | 亏损收窄，芯片业务高增 |
| **壁垒** | 架构授权 + 生态 | 完全自主 | 军工资质+技术 |

## 四、投资建议

### 1. 首选标的：**海光信息**
- **逻辑**：盈利能力强 + 商业化成熟 + 双线技术壁垒
- **定位**：国产高端处理器龙头，兼具确定性+成长性

### 2. 高弹性标的：**龙芯中科**
- **逻辑**：完全自主指令集 + 生态拐点 + 信创渗透深化
- **定位**：生态独立性最强，适合风险偏好较高的投资者

### 3. 军工+AI 双主题：**景嘉微**
- **逻辑**：国产 GPU 稀缺标的 + 军工需求稳定 + 芯片业务高增
- **定位**：适合博弈 AI 算力国产替代的投资者

---

## 五、风险提示

1. **供应链风险**：美国制裁升级影响先进制程、EDA 工具、关键材料
2. **技术迭代风险**：性能、功耗、交付周期若无法领先，份额可能被挤压
3. **生态建设风险**：软件适配滞后影响市场接受度
4. **估值过高**：部分标的 PE 超 200 倍，若业绩不及预期存在回调压力
5. **需求波动**：信创落地节奏、政务预算、AI 算力需求波动
