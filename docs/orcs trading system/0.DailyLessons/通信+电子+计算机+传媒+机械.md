















# 光通信



## 板块简介

光通信产业在5G大规模部署的背景下，产业高歌猛进，市场持续升温，呈现高增长态势。

光模块作为数据中心的重要组成部分，未来几年将保持较高速度扩张，尤其是超高速的光模块需求增加为光模块厂商提供了机遇。

# WIND函数

































##   流通市值(亿元)

【函数名称】
        流通市值(亿元)

【函数格式】
        hks_dq_mv(wind代码,交易日期,币种)

【参数描述】
        WindCode：证券Wind代码或交易代码。
        date：交易日，如不设置则默认为本机的系统日期。

【释义】
        在指定交易日，指定证券已发行且上市的股份市值。比如，万科分别输入A股000002.SZ和港股代码2202.HK，返回的分别是A股市值（含限售流通股），港股市值。

【算法】
        流通市值=指定证券指定交易日收盘价*截至日该证券的发行上市股数

【参数】
        Wind代码,交易日期,币种

【来源】
        Wind计算

【单位】
        元

【精度】
        0.0000









##    自由流通市值

【名称】
        自由流通市值

【公式】
        share_freesharesmv(Wind代码,交易日期)

【参数描述】
        WindCode：证券Wind代码或交易代码。
        tradeDate：交易日期，如不设置则默认为本机的系统日期。

【释义】
        Wind自己计算的截至该日股票的自由流通股市值：（流通股本- 其他扣除数）*股价
注：
1、该指标为不可回测指标
2、交易日参数匹配的是股本变化日（除权日）

【算法】
        Wind自己计算的截至该日股票的流通股市值（自由流通股本*股价）：（流通股本- 其他扣除数）*股价，其他扣除数主要包括：
        1.持股>=5%的大股东持有的流通股份；
        2.持股<5%的股东持有的流通股份,考虑一致行动人(即和>=5%股东有关联关系或者虽然持股<5%,但关联方累计>=5%)；
        3.前10大股东或前10大流通股东中公布的高管持股数,一般全流通情况下扣除75%,(因为公司法规定高管每年实际可流通的不超过其持股数的25%,其他情况视上市公司具体公布情况)；

【参数】
        Wind代码,交易日期

【来源】
        Wind计算

【单位】
        元

【精度】
        0.0000

【释义】
        上市公司的股权公平市场价值。对于一家多地上市公司，区分不同类型的股份价格和股份数量分别计算类别市值，然后加总。
注：优先股不适用此类估值方法，指定证券的类型为优先股时，该指标返回为空；非流通股参照主上市地证券价格纳入总市值的计算。

【算法】
        A股收盘价*A股合计+B股收盘价*B股合计*人民币外汇牌价+H股收盘价*H股合计*人民币外汇牌价＋海外上市股收盘价*海外上市股合计*人民币外汇牌价
        其中：
        1、各类别市值按指定日人民币外汇牌价转换为人民币后加总，然后转换为指定证券的交易币种进行展示。指定币种选择原始币种时，展示交易币种；但交易币种为辅币时，转换为交易币种对应主币进行展示。
        2、指标不可回测：由于指定日股本或财务数据在数据提取日之后可能存在上市公司披露变更情形，因此不同日期提取的指定日数据可能会不同。

【参数】
        Wind代码,交易日期

##  总市值2

## 区间涨跌幅

【名称】
        区间涨跌幅

【公式】
        s_pq_pctchange(Wind代码,起始交易日期,截止交易日期)

【参数描述】
        WindCode：证券Wind代码或交易代码。
        startdate：区间首日。
        enddate：区间尾日。

【释义】
        区间涨跌幅，即考虑分红再投资的区间回报率。以起始交易日为基点，按照分红再投资的调整计算方法，先算出截止交易日的收盘价，然后用该收盘价和起始交易日前收盘价计算区间涨跌幅。

【算法】
        区间涨跌幅=[(区间最后交易日收盘价-区间首个交易日前收盘价)／区间首个交易日前收盘价]*100%
        注：
        1、行情数据系后复权行情。
        2、如果区间内包含上市首日，则计算时剔除上市首日涨跌幅

【参数】
        Wind代码,起始交易日期,截止交易日期

【来源】
        Wind计算

【单位】
        %

【精度】
        0.0000
