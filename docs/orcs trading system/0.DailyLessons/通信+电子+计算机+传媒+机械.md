















# 光通信



## 板块简介

光通信产业在5G大规模部署的背景下，产业高歌猛进，市场持续升温，呈现高增长态势。

光模块作为数据中心的重要组成部分，未来几年将保持较高速度扩张，尤其是超高速的光模块需求增加为光模块厂商提供了机遇。





## 通信/计算机/电子行业研究员和研究机构

- 新财富是中国本土第一份民间市场化分析师排名，在“公开、公平、公正”原则指引下，受到越来越多的证券研究机构及广大机构投资者的认可，已经成为业内公认的最具权威性的证券分析师排名，影响力日益扩大。对提升证券分析师影响力，倡导“研究创造价值”的理性投资观念，推动资本市场健康发展起到了积极作用。
