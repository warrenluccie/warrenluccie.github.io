



# Daily Review |  每日复盘

## 行业资金流向

- **每交易日观察行业及板块之间的资金流向**

行业主力资金流向即刻获取，Excel插件行业资金流向模板，实时展示万得全A成交数据以及各行业分类下的主力资金流入流出情况。





## 南向资金流入流出

探索南向资金的秘密！该模板为您呈现南向资金的实时与历史流入流出情况，让您一目了然市场风向。















# Monthly Review | 每月复盘



## 月度收益

该模板可以查看所选标的在历史上的月度收益表现，可以进行月份、季节效应等方面的研究。







## 价差分析

通过该模板，可以快速获取目标公司及对比公司的股价与价差走势，同时支持查看价差的具体分布统计情况。







# 期货

## 国债期货CTD综合监控(2年期)

国债期货最廉券综合监控，展示 2 年期国债期货主力合约的日内行情数据及全市场最廉券的IRR走势。





## 国债期货对冲分析

国债正向期现套利策略的盈亏分析，期初买入现券（组合）的同时卖空期货，持有至到期并将现券（组合）用于交割。





## 国债期货价差分析

国债期货的跨期限价差分析，实时展示国债期货的日内行情及价差的统计学分析图表。







# 设置分组

点击工具栏“分组”按钮，并将某字段设置为分组条件，信息就能以该字段为维度进行分类。当选择多个分组条件时，可根据顺序逐层分组
