





# 求则得之，舍则失之

- 孟子曰：“求则得之，舍则失之，是求有益于得也，求在我者也。求之有道，得之有命，是求无益于得也，求在外者也。”（出自《孟子·尽心章句上》
- **翻译：孟子说：“追求就得到，放弃就失去，所以追求有利于得到，所求得与否在于我。追求有一定的方法，能否得到却取决于天命，这种追求无益于得到，因为所追求的东西都是身外之物。”**

孟子曰：「求則得之，舍則失之，是求有益於得也，求在我者也。求之有道，得之有命。」

程子曰：「求之雖有道，奈何得之却有命？」是求無益於得也，求在外者也。

此章爲警告未達者言也。言求在我者，有益於得，所以擴其天理也；言求在外者，無益於得，所以遏其人欲也。所謂求而得，舍而失者，心之謂也。求與舍，得失毫釐之分，然則可不勉於求歟？所謂求之有道，得之有命者，富貴利達之謂也。富貴利達，衆人謂己有求之之道，然不知其有命焉，固有求而得之者矣。是亦有命，而非求之能有益也。蓋亦有巧求之而不得者多矣。以此可見其無益於得也。然則亦可以已矣。程子曰：「賢者惟知義而已，命在其中。中人以下，乃以命處義。」如言求之有道，得之有命，是求無益於得。知命之不可求，故自處以不求。若賢者，則求之以道，得之以義，不必言命。孟子所言「求之有道」，謂自以爲求之有道者也。程子所言「求之以道」者，謂守其道而不妄求者也。求之以道，故其得之未嘗不以義焉。若是者，惟道義之安，而命在其中，比之以命爲不可強而不求者，又有間矣。故曰：孟子斯言，爲警告未達者言也。
