# 二、MySQL 生产级表结构设计

## 1️⃣ 原始行情表（Raw Layer）

```sql
CREATE TABLE fut_daily_raw (
    symbol        VARCHAR(10) NOT NULL,
    contract      VARCHAR(20) NOT NULL,
    trade_date    DATE NOT NULL,

    open          DECIMAL(12,4),
    high          DECIMAL(12,4),
    low           DECIMAL(12,4),
    close         DECIMAL(12,4),
    volume        BIGINT,
    open_interest BIGINT,
    settlement    DECIMAL(12,4),

    PRIMARY KEY (contract, trade_date),
    KEY idx_symbol_date (symbol, trade_date)
) ENGINE=InnoDB;
```

> **注意**：Raw 层**不做任何计算、不覆盖历史**

------

## 2️⃣ 连续合约表（Clean Layer）

```sql
CREATE TABLE fut_daily_continuous (
    symbol      VARCHAR(10) NOT NULL,
    trade_date  DATE NOT NULL,

    open        DECIMAL(12,4),
    high        DECIMAL(12,4),
    low         DECIMAL(12,4),
    close       DECIMAL(12,4),
    volume      BIGINT,
    oi          BIGINT,

    adj_factor  DECIMAL(16,8),
    main_contract VARCHAR(20),

    PRIMARY KEY (symbol, trade_date)
);
```

------

## 3️⃣ 因子主表（Factor Core）

> **这是量化系统的“心脏”**

```sql
CREATE TABLE fut_factor_daily (
    symbol      VARCHAR(10) NOT NULL,
    trade_date  DATE NOT NULL,

    -- 波动类
    swing_pct       DECIMAL(8,4),
    atr_14          DECIMAL(10,6),
    vol_std_20      DECIMAL(10,6),

    -- 趋势类
    ret_1           DECIMAL(10,6),
    ret_5           DECIMAL(10,6),
    ma_5            DECIMAL(12,4),
    ma_20           DECIMAL(12,4),
    trend_strength  DECIMAL(10,6),

    -- 量能类
    vol_ma_5        DECIMAL(14,4),
    vol_ma_20       DECIMAL(14,4),
    oi_change       DECIMAL(10,6),

    -- 统计类
    zscore_ret_20   DECIMAL(10,6),
    skew_20         DECIMAL(10,6),

    PRIMARY KEY (symbol, trade_date),
    KEY idx_trade_date (trade_date)
) ENGINE=InnoDB;
```

> **原则**：
>
> - 一个字段 = 一个稳定数学定义
> - 禁止混合信号含义

```python
import pandas as pd
import numpy as np
from statsmodels.tsa.stattools import adfuller
from sqlalchemy import create_engine

engine = create_engine(
    "mysql+mysqlconnector://user:pwd@host:3306/db"

sql = """
SELECT symbol, trade_date, open, high, low, close, volume, oi
FROM fut_daily_continuous
ORDER BY symbol, trade_date
"""

df = pd.read_sql(sql, engine, parse_dates=["trade_date"])
```

------

### 2️⃣ 基础派生字段

```python
g = df.groupby("symbol")

df["pre_close"] = g["close"].shift(1)
df["ret_1"] = df["close"] / df["pre_close"] - 1
df["ret_5"] = df["close"] / g["close"].shift(5) - 1
```

------

### 3️⃣ 波动类因子

#### SWING（振幅）

```python
df["swing_pct"] = (df["high"] - df["low"]) / df["pre_close"] * 100
```

#### ATR(14)

```python
tr = pd.concat([
    df["high"] - df["low"],
    (df["high"] - df["pre_close"]).abs(),
    (df["low"] - df["pre_close"]).abs()
], axis=1).max(axis=1)

df["atr_14"] = tr.groupby(df["symbol"]).rolling(14).mean().reset_index(0, drop=True)
```

------

### 4️⃣ 趋势类因子

```python
df["ma_5"] = g["close"].rolling(5).mean()
df["ma_20"] = g["close"].rolling(20).mean()

df["trend_strength"] = (df["ma_5"] - df["ma_20"]) / df["ma_20"]
```

------

### 5️⃣ 量能 & 持仓

```python
df["vol_ma_5"] = g["volume"].rolling(5).mean()
df["vol_ma_20"] = g["volume"].rolling(20).mean()

df["oi_change"] = g["oi"].pct_change()
```

------

### 6️⃣ 统计类（Statsmodels）

```python
df["zscore_ret_20"] = (
    (df["ret_1"] - g["ret_1"].rolling(20).mean())
    / g["ret_1"].rolling(20).std()
)

df["skew_20"] = g["ret_1"].rolling(20).skew()
```

# 一、IC 体系定位（先统一认知）

### 1️⃣ IC 的本质

Information Coefficient：


IC_t = Corr(Factor_t,\ Return_{t+1})
]

衡量：

> **因子在 t 时刻，对未来收益排序的解释能力**

期货实务中，99% 用：

- **Rank IC（Spearman）** ✅（主流）
- Pearson IC（辅助）

------

### 2️⃣ 推荐标准口径（期货）

| 项目     | 规范            |
| -------- | --------------- |
| 因子时点 | T 日收盘        |
| 收益     | T+1 → T+n       |
| 截面     | 同品种 / 全市场 |
| 方法     | Rank IC         |
| 周期     | 日频滚动        |

# 四、IC 核心计算引擎（主代码）

## 1️⃣ 拉取数据

```python
sql = """
SELECT
    f.symbol,
    f.trade_date,

    f.swing_pct,
    f.atr_14,
    f.trend_strength,

    r.ret_fwd_5
FROM fut_factor_daily f
JOIN fut_forward_return r
ON f.symbol = r.symbol
AND f.trade_date = r.trade_date
"""

df = pd.read_sql(sql, engine, parse_dates=["trade_date"])
```

## 2️⃣ Rank IC 计算框架（标准版）

```python
from scipy.stats import spearmanr

def calc_rank_ic(df, factor, ret_col):
    res = []

    for dt, g in df.groupby("trade_date"):

        x = g[factor]
        y = g[ret_col]

        mask = x.notna() & y.notna()

        if mask.sum() < 10:
            continue

        ic, _ = spearmanr(x[mask], y[mask])

        res.append({
            "trade_date": dt,
            "factor": factor,
            "ic": ic
        })

    return pd.DataFrame(res)
```

------

## 3️⃣ 批量评估所有因子

```python
factor_list = [
    "swing_pct",
    "atr_14",
    "trend_strength"
]

all_ic = []

for fac in factor_list:
    tmp = calc_rank_ic(df, fac, "ret_fwd_5")
    tmp["horizon"] = 5
    all_ic.append(tmp)

ic_df = pd.concat(all_ic)
```

# 五、IC 统计评估（IR / 稳定性）

## 1️⃣ 60 日滚动统计

```python
g = ic_df.groupby("factor")

ic_df["ic_mean_60"] = g["ic"].rolling(60).mean().reset_index(0, drop=True)
ic_df["ic_std_60"] = g["ic"].rolling(60).std().reset_index(0, drop=True)

ic_df["ic_ir_60"] = ic_df["ic_mean_60"] / ic_df["ic_std_60"]
```

------

## 2️⃣ 显著性检验（Statsmodels）

```python
from statsmodels.stats.weightstats import ztest

def ic_significance_test(ic_series):
    z, p = ztest(ic_series.dropna(), value=0)
    return z, p
```
